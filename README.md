# Incident Report — Practice Write-Up

A practice incident report I wrote as part of my cybersecurity learning.

**The published version is on LinkedIn:**
https://lnkd.in/p/eajvZace

## Report structure I used

```text
1. Incident summary      what happened, when it was noticed
2. Detection             how it was discovered, what triggered it
3. Timeline              what happened and when, in order
4. Impact                systems, data and people affected
5. Containment           what was done to stop it spreading
6. Eradication & recovery how the cause was removed and service restored
7. Root cause            why it happened
8. Lessons learned       what changes prevent a repeat
9. Recommendations       owner and deadline for each change
```

## Why I practised this

Incident reporting is the part of security work that turns a technical event
into something a business can act on. My background is in physical security
operations — CCTV and alarm monitoring, access control, and writing incident
and compliance reports for management review — so I already worked to this
discipline; this work moves it into a cyber context.
